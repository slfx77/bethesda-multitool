; MemDebug pass IDs 700/701 are inside BSSM_UNUSEDPASSES_FIRST..LAST (673..755), and the
; captured retail BSSM_SV_2_A / PS 3.0 configuration selects GetRenderPasses_2x. These equations
; are retained for package audit only; they are not evidence that retail submits this PS1 family.
;
; Stage-local identities are from the MemDebug PDB symbol table; instructions are disassembled
; from Data/Shaders/shaderpackage003.sdp with tools/disasm_shader.py. VS and PS package numbers
; are independent indices: PS 1010 is fog, while VS 1012 and PS 1013 are vertex-color variants.
;
;   PS 1009 = SLS_PS1_PPAMBDIFFUSETEXTUREDIR
;   PS 1010 = SLS_PS1_PPAMBDIFFUSETEXTUREDIR_F   (fog)
;   PS 1011 = SLS_PS1_PPAMBDIFFUSETEXTUREDIR_A   (material alpha)
;   PS 1012 = SLS_PS1_PPAMBDIFFUSETEXTUREDIR_AF  (material alpha + fog)
;   PS 1013 = SLS_PS1_PPAMBDIFFUSETEXTUREDIR_Vc  (vertex color)
;   PS 1014 = SLS_PS1_PPAMBDIFFUSETEXTUREDIR_VcF (vertex color + fog)
;   PS 1015 = SLS_PS1_PPAMBDIFFUSETEXTUREDIR_VcA (vertex color + material alpha)
;   PS 1016 = SLS_PS1_PPAMBDIFFUSETEXTUREDIR_VcAF
;   VS 1010 = SLS_VS1_PPAMBDIFFUSETEXTUREDIR
;   VS 1011 = SLS_VS1_PPAMBDIFFUSETEXTUREDIR_F   (fog)
;   VS 1012 = SLS_VS1_PPAMBDIFFUSETEXTUREDIR_Vc  (vertex color)
;
; Direct disassembly of PS 1011/1012/1015/1016 shows that A/AF changes only output alpha to
; BaseMap.a * AmbientColor.w. Vc/VcF/VcA/VcAF declares vertex color as xyz; authored vertex alpha
; is not a coverage input anywhere in this family.
